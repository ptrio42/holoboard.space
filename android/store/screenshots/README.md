# Zapstore screenshots

These are unedited captures of the current Holoboard frontend at a 390 by 844
CSS-pixel viewport and device scale 2. They show the Android 1.1.0 release's board,
Post, Budget, Billboard preview and Invoice / QR screens.

The notes, profile names, ranking amounts and link metadata are controlled
fictional examples. The QR is a valid-format fixture invoice with no receiving
wallet. No funds were sent and no posts were published. The screenshots do not
establish physical Android, wallet or signer interoperability.

Capture the actual application with the versioned production feature profile
before replacing these files. Keep HTTP APIs and Nostr transport controlled,
block public writes and verify that preparing an invoice sends no payment.
Keep `zapstore.yaml` in sync with the selected PNG files. Website features must
be deployed with their compatible backend before publishing the APK listing.
